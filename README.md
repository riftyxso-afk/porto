# I Wayan Radea — Developer Portfolio

Production-grade, minimalistic developer portfolio built with the latest **Next.js 15 (App Router)**, **React 19**, **Tailwind CSS v4**, and **TypeScript**.

## ✨ Features

- **Next.js 15 App Router**: Server Components by default with selective Client Components where interaction is needed.
- **Tailwind CSS v4**: Minimalist, clean editorial layout with technical grid lines and corner crosshair accents.
- **Dark & Light Mode**: Theme toggle powered by `next-themes` with persistent state.
- **Interactive Experience Timeline**: Expandable role achievements, responsibilities, and tech tags with rounded branch connector.
- **Live Local Time**: Client hydration-safe live Bali (WITA, UTC+8) clock.
- **Project Showcase**: Balanced 2-column cards featuring Portalink and Whip.
- **Numbered Tech Stack**: Categorized stack matrix (Languages, Frontend, Backend, Data, Cloud, AI) with high-fidelity vector icons.
- **Interactive GitHub Graph**: 52-week activity calendar heatmap with 5-level color scale and legend.
- **Floating Command Bar**: "Ask Radea..." sticky bottom pill with backdrop blur.
- **Geist & Caveat Typography**: Crisp typography using `next/font/google`.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Running Locally
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.
